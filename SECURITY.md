# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our platform and interface contracts seriously. If you believe you have found a security vulnerability in this repository:

1. **Do NOT disclose the vulnerability publicly.**
2. Send a detailed report directly to the sovereign architect:
   - **Email:** `im@mohamedosama.me`
3. Please include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Impact assessment.

We will acknowledge receipt within 24 hours and provide an estimated timeline for remediation.
