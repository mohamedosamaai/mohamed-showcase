# Contributing to Mohamed Osama Architecture Showcase

Thank you for your interest in contributing to the open interface contracts and showcase repository!

## Development Workflow

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/mohamedosamaai/mohamed-showcase.git
   cd mohamed-showcase
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Typecheck and build:
   ```bash
   npm run lint
   npm run build
   ```

4. Conventional Commits:
   All commits must follow Conventional Commits format (`feat:`, `fix:`, `docs:`, `chore:`).

5. Submit a Pull Request.
